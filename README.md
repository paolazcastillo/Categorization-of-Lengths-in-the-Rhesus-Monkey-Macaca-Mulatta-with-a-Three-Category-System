# Categorization-of-Lengths-in-the-Rhesus-Monkey-Macaca-Mulatta-with-a-Three-Category-System
MATLAB + Psychtoolbox behavioural task suite for the Merchant Lab rig: center-out length categorization and center-in hold training, run from one operator console, with joystick input and TDT Synapse/RZ2 reward and event markers over UDP.
